# cpp-modules
A collection of C++ projects designed to master the fundamentals of Object-Oriented Programming (OOP) and core language mechanics, building solid foundations for writing and reading production-ready C++ code.

## Overview & Learning Objectives

| Module | Core Theme | Key Concepts & Topics Covered |
| :--- | :--- | :--- |
| **`cpp-00`** | **Introduction to OOP** | Namespaces, classes, member functions, `std::cout` / `std::cin`, `const` qualifiers, initialization lists, static members |
| **`cpp-01`** | **Memory & References** | Dynamic allocation (`new` / `delete`), stack vs heap, pointers vs references, pointers to members, file streams (`std::ifstream`, `std::ofstream`) |
| **`cpp-02`** | **Ad-hoc Polymorphism & Canonical Form** | Operator overloading, fixed-point number representation, Coplien's Canonical Form (default constructor, copy constructor, assignment operator, destructor) |
| **`cpp-03`** | **Inheritance** | Base and derived classes, access specifiers (`public`, `protected`, `private`), constructor/destructor chaining, diamond problem |
| **`cpp-04`** | **Subtype Polymorphism & Abstraction** | Virtual functions, virtual destructors, pure virtual functions, abstract classes, interfaces, deep vs shallow copy |
| **`cpp-05`** | **Exception Handling** | `try`, `catch`, `throw` blocks, custom exception classes (`std::exception`), nested classes, design resilience |
| **`cpp-06`** | **C++ Type Casting** | C++ explicit casts: `static_cast`, `dynamic_cast`, `reinterpret_cast`, `const_cast`, scalar conversion, serialization |
| **`cpp-07`** | **Templates** | Function templates, class templates, template instantiation, explicit specialization |
| **`cpp-08`** | **STL Containers & Algorithms** | Sequential and associative containers (`std::vector`, `std::list`, `std::map`), iterators, STL algorithms (`std::for_each`, `std::find`, etc.) |
| **`cpp-09`** | **Advanced STL Applications** | Container selection & trade-offs, expression evaluation (Reverse Polish Notation), merge-insert sort algorithm (Ford-Johnson) |
